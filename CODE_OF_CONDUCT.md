# Code of conduct

SaaS Monitor follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind, welcoming and constructive, in issues, pull requests and anywhere the project is
discussed.

Report unacceptable behavior privately to the maintainers at contact@loan-dev.fr. Every report is
reviewed and kept confidential. Maintainers may remove, edit or reject contributions that do not
follow this code, and ban contributors who repeatedly ignore it.
